# varolusstudio.github.io

Website for Varolus Studio, a software development studio (analytics software, digital transformation, digital twins and edge AI), served by GitHub Pages.

| File | Purpose |
|---|---|
| `index.html` | Home page: services, approach, what we build, contact |
| `contact.html` | Contact details |
| `data-deletion.html` | How users delete app data (for Play Data safety) |
| `privacy.html` | Privacy policy for apps published on Google Play (URL used in Play Console) |
| `terms.html` | Terms of use for apps |
| `support.html` | App support / FAQ |
| `app-ads.txt` | AdMob authorised sellers (replace with the AdMob line when the AdMob account exists) |
| `404.html` | Not-found page |
| `styles.css` | Shared styles |
| `assets/logo-mark-white.png` | Logo mark for the navy header |
| `assets/fonts/` | Archivo variable font, self-hosted (SIL OFL 1.1, see `OFL.txt`) |

No cookies, analytics or third-party requests. Keep `privacy.html` in sync with what the apps actually do and update its date on every change.
