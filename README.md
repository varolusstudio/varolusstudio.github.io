# varolusstudio.github.io

Static website for Varolus Studio, served by GitHub Pages.

| File | Purpose |
|---|---|
| `index.html` | Home page (developer website for Google Play) |
| `privacy.html` | Privacy policy for Timber Slide: Picture Puzzle |
| `support.html` | Support / FAQ / contact |
| `terms.html` | Terms of use |
| `app-ads.txt` | AdMob authorised sellers (replace with the AdMob line at M8) |
| `404.html` | Not-found page |
| `styles.css` | Shared styles (no external fonts, no trackers) |

Keep `privacy.html` in sync with the app's actual SDKs and behaviour, and update the "Last updated" date on every change.
